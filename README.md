CHROMA CASCADE is an original spectrum-defense arcade game. Rotate the Prism Core to match incoming color signatures, chain hits into escalating combos, evolve the reactor, and defeat the Void Emperor before the Lumen Vault goes dark.

## Run locally

Requires Node.js 22 or newer; no install step or external assets are needed.

```sh
node serve.ts --port 8081
```

Open `http://localhost:8081`.

## Controls

- `A` / `D` or `←` / `→`: rotate the active spectrum.
- `Space`: fire Spectrum Nova when the charge reaches 100%.
- `P`: pause or resume.
- `R`: restart after a run.
- Tap/click either side of the Prism Core to rotate.

## Mechanics

- Five-color spectrum matching against escalating radial enemy swarms.
- Combo scoring, charge economy, Nova overdrive, and three-choice upgrade drafts.
- A moving Void Emperor boss encounter with a visible health bar.
- Integrity defense, explicit victory and defeat states, procedural canvas VFX, and Web Audio synthesis.
- Deterministic seeded enemy patterns; no third-party game assets or runtime dependencies.
